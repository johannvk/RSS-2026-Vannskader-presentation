# Basic Presentation Template for NR using Beamer

This is a simple LaTeX template for presentations loosely based on the
NR PowerPoint template. It uses [beamer](https://ctan.org/pkg/beamer),
but provides some things already set up for you.

## Usage

Simply clone or download the repository and rename
`nr-presentation.tex` to a good name that fits your liking and begin
working on your presentation!

Background images for the presentation is found in `backgrounds`.
Three background images are provided, but you can add additional if
you want.

1. [nr1 – Title slide background](backgrounds/nr1.pdf)
1. [nr2 – All white background with logo](backgrounds/nr2.pdf)
1. [nr3 – End slide background](backgrounds/nr3.pdf)

The defaults should be OK, but you can do whatever you normally need
to do in beamer to make your presentation great.
